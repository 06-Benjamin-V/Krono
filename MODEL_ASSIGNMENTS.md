# Agent model assignments

All models below are taken from the user's available OpenCode free-model list.

| Agent | Model |
|---|---|
| skynet | `opencode/muse-spark-1.3-contributor-free` |
| architect | `opencode/nemotron-3-ultra-free` |
| frontend | `opencode/ling-3.0-flash-fin-free` |
| mobile | `opencode/muse-spark-1.2-contributor-free` |
| database | `opencode/mimo-v2.5-free` |
| tester | `opencode/nemotron-3.5-lightning-free` |
| qa | `opencode/big-pickle` |
| documenter | `opencode/mimo-v2.5-free` |

Rationale:

- Skynet gets Muse Spark 1.3 for orchestration and broad code reasoning.
- Architect gets Nemotron 3 Ultra for deeper structural reasoning.
- Frontend gets Ling 3.0 Flash Fin for fast iterative coding.
- Mobile gets Muse Spark 1.2 as a stable coding-oriented fallback for Android/Capacitor work.
- Database and documentation use MiMo V2.5 for efficient implementation/documentation.
- Tester gets Nemotron 3.5 Lightning for fast test generation and edge-case analysis.
- QA gets Big Pickle as an independent reviewer, reducing correlated mistakes with the implementation agents.
